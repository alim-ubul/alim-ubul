JobHunter Agent
AI 求职全流程智能体 — 本地优先、真实护栏、全流程闭环
简历解析 | JD 匹配 | 简历优化 | 面试预测 | 求职追踪
为什么做它： 求职是高频、高焦虑、强信息差的场景。现有工具要么只做单点改简历，要么让你把简历"交出去"。我的答案是本地优先——数据留在自己手里，开源可私有化部署。
核心亮点：
✅ 三道真实性护栏：AI 只改表达、不编造事实，量化数字必须有来源
✅ LLM 唯一出口：Pydantic 契约校验 + 三重 JSON 兜底 + 全量调用留痕
✅ 黄金集回归：改 Prompt / 换模型必跑回归，防止 AI 功能退化
✅ 成本可控：默认 DeepSeek，MVP 单次成本 < ¥0.01
